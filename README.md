# المكتبة القانونية الشاملة — MCP v0.1.1

**فكرة المشروع والإشراف العلمي:** الدكتور قيس الهيازعي والدكتورة أسيل النوري.

**الجهة الأكاديمية المذكورة:** وزارة التعليم العالي والبحث العلمي / جامعة الفلوجة (للتعريف فقط، دون ادعاء اعتماد رسمي).

**حقوق المشروع:** راجع `AUTHORS.md` و`NOTICE.md`. لم تُحدد رخصة الشيفرة بعد، ولم يُنشر الخادم للعامة.


## ما يعمل الآن
- دليل 9 مداخل قانونية رسمية (لا يعني أنها متصلة برمجياً).
- بحث حي في فهرس التشريعات البريطانية الرسمي عبر Atom feed.
- بحث واسترجاع وثائق قانونية محلية مستوردة بموافقة واضحة، عبر SQLite.
- قالب توثيق يوضح أن البيانات المدخلة غير متحقق منها.

## المتطلبات
Python 3.11+، اتصال بالإنترنت للبحث البريطاني فقط.

## التشغيل المحلي
```bash
python -m venv .venv
# Windows PowerShell:
.venv\Scripts\Activate.ps1
# Linux/macOS: source .venv/bin/activate
pip install -r requirements.txt
python server.py
```
المسار المحلي المعتاد: `http://localhost:8000/mcp`.

## الاختبار
```bash
pytest -q
npx -y @modelcontextprotocol/inspector
```
في Inspector اختر Streamable HTTP وأدخل `http://localhost:8000/mcp`.

## استيراد وثائق مصرح بها
عدّل `example_import.jsonl` وأدخل وثائق أصلية مسموح باستخدامها ثم:
```bash
python import_documents.py example_import.jsonl --confirm-rights
```
لا تستورد قواعد بيانات تجارية أو وثائق محمية دون إذن. لا تفترض أن كل قانون أو حكم محدث أو نافذ.

## النشر والربط بـ ChatGPT
1. استضف المشروع على خدمة تدعم Python أو Docker مع HTTPS وقرص بيانات دائم.
2. شغّل `python server.py` على المنفذ 8000؛ قد تحتاج ضبط HOST/PORT بحسب SDK والمنصة.
3. تأكد من ظهور `https://YOUR-DOMAIN/mcp` عبر MCP Inspector قبل الربط.
4. من إعدادات ChatGPT افتح إعدادات التطبيقات/المكونات أو وضع المطور، إن كان متاحاً لحسابك، ثم أضف عنوان MCP المنشور.
5. **لا تنشر هذا الخادم للاستخدام العام كما هو**: النسخة التجريبية بلا مصادقة، وبلا حدود طلبات أو عزل للمستخدمين. أضف OAuth أو بوابة مصادقة متوافقة مع MCP، وتحقق من Origin، وحدود المعدل، وTLS، وسياسات السجلات قبل النشر.

## حدود النسخة الأولى
- المصادر العراقية والعربية والفرنسية والأوروبية والأمريكية في `directory_only`، وليست واجهات بحث مباشر.
- لا يوجد استخراج آلي من PDF أو OCR أو مزامنة تعديلات القوانين.
- لا يوجد ادعاء بأن التوثيق يتحقق تلقائياً من صحة المادة أو الحكم أو النفاذ.
- لا يتضمن المشروع نصوص قوانين حقيقية مدمجة؛ تُضاف بعد التحقق من المصدر والإذن.

## التطوير التالي
مصادقة متعددة المستخدمين، واجهة استيراد PDF مرخصة، فهرس عربي FTS، ربط واجهات حكومية موثقة، توثيق على مستوى المادة والصفحة، تتبع التعديلات، اختبارات تكامل حيّة.
